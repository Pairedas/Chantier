# Chantier Salon

Application web pour suivre toutes les dépenses du chantier du salon, des briques à la finition.

**Ouvrir l'appli :** https://pairedas.github.io/Chantier/

- Étapes du chantier avec budget et avancement
- Dépenses (quantité × prix unitaire, fournisseur, espèces / Wave / Orange Money, crédit)
- Artisans au forfait : prix convenu, avances, reste à payer
- Total dépensé, reste à payer, coût final estimé
- Saisie en vrac d'une liste, bilan à partager, export Excel

Les données restent uniquement sur le téléphone (rien n'est envoyé sur GitHub).

Tests de la logique : `node tests/test_logique.js`
